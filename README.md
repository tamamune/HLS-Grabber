# HLS Grabber（試作版 v0.1.0）

ページ内のHLS（m3u8）ストリームを検出して、ダウンロードやライブ録画をするChrome拡張（Manifest V3）です。

## インストール
1. zipを展開する
2. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で `hls-grabber` フォルダを選ぶ

## 使い方
1. 動画ページで動画を再生する → m3u8が見つかるとアイコンに赤い数字（件数）が付く
2. アイコンをクリック → 「ダウンロード / 録画」を押す
3. 開いたタブで画質を選んで「ダウンロード開始」を押す
   - VOD: 終わると自動で保存される（「途中で停止して保存」も可）
   - ライブ: 開始した時点から録画が始まる。「録画停止して保存」で書き出す

## 対応していること
- マスタープレイリスト（画質選択）／メディアプレイリスト
- AES-128暗号化（IV指定あり／省略の両方）
- MPEG-TS → `.ts` で保存、fMP4（EXT-X-MAP）→ `.mp4` で保存
- EXT-X-BYTERANGE
- ライブ録画（プレイリストを定期的に再取得）
- 元ページのRefererとOriginを付けてリクエストする（Referer制限のあるサーバー対策）
- 並列ダウンロード（同時接続数は1〜16）、リトライ、取得に失敗したセグメントは飛ばして続行
- 一時保存はOPFS（ディスク）に順番に書き込むので、長い動画でもメモリを圧迫しにくい

- MP4変換（`.ts` → `.mp4`）: 同梱の mux.js 6.3.0 でダウンロード中にセグメントごとに変換してディスクへ書くので、サイズ上限なし・ライブ録画でも可（出力は fragmented MP4）
- 別トラック音声の映像への結合: 同梱の ffmpeg.wasm 0.12（`-c copy` なので再エンコードなし。VODのみ、合計1.5GBまで。失敗時は元の形式で保存）
- X (Twitter) の画像（原寸）とMP4動画を検出して、ポップアップから保存（サムネ付き）
- Instagram の画像と動画を検出して保存（DASH の映像＋音声は ffmpeg.wasm で結合。サイト側の変更で動かなくなることがある）
- 字幕（WebVTT）を `.vtt` で保存
- ファイル名テンプレート（`{title}` `{date}` `{time}`）、同時接続数・テンプレート・自動停止の設定を記憶
- ライブ録画の自動停止（分指定）、進捗をタブのタイトルに表示
- ポップアップでマスター／VOD／ライブの種別を表示
- 手動／自動開始の切り替え（ポップアップ右上）。自動開始: ポップアップで「ダウンロード / 録画」を押して開いた画面で、開始ボタンを自動で押す（既定の最高画質・ライブも開始）。ページを開いただけでダウンロードが始まることはない

## 未対応・制限
- DRM（Widevine / PlayReady / FairPlay、SAMPLE-AES）には対応しない
- ライブ録画では音声結合は使えない（VODのみ）。音声結合は wasm のメモリ制限で合計1.5GBまで
- 字幕トラック、LL-HLSのパーツ（EXT-X-PART）
